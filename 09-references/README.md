# 09-references

Primary sources: contracts, vendor docs, regulations, exported architecture
material. **Binary files live here; knowledge does not.** Every source gets a
row in a **source register** — the index that gives it an ID (`SRC-XXX`),
a trust classification, and a place to record conflicts between sources.

- One register per intake or per topic: copy `source-register-template.md`.
- File naming: `YYYY-MM-<parties>-<topic>.<ext>`; use the `undated-` prefix
  when the date is unknown (and note it in the register).
- Never store credentials or unnecessary personal data — reference redacted
  copies if needed.
