# Periodic validation check

> A simple, ~15-minute update the client team can complete **without the
> consultant present**. Run per cadence (`02-organization/ways-of-working.md`).

| Field | Answer |
|---|---|
| Date | |
| Area / module reviewed | |
| Client participants | |
| Vendor/team participants | |
| Next session | |

## The seven questions

1. **What concrete case was tested?** One sentence.
2. **What was the result?** `IMPLEMENTED` / `PARTIAL` / `NOT IMPLEMENTED` / `NOT VALIDATED`.
3. **What evidence remains?** Screen name + capture, test record ID, or report. No sensitive personal data.
4. **What is missing or worked differently than expected?** One sentence.
5. **Who owns the next step?** One named person.
6. **By when?** One date.
7. **Does the client need to decide a rule?** Yes/No. If yes, write the question — never invent the answer.

## Closing rule

Do not review everything in one session. Close at most **three rows** and
carry the rest to the next one.
